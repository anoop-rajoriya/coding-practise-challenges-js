An FAQ accordion is a UI pattern that lets users expand or collapse answers to questions by clicking the header. Under the hood, JavaScript listens for click events and toggles a CSS class (like active) to reveal or hide the corresponding answer panel.
classList.toggle() checks if an element already contains a specified class. If it does, it removes it; if it doesn't, it adds it. This makes state switching clean and eliminates manual conditional check blocks like if/else for adding or removing classes.
In this implementation, each item operates independently, allowing you to open or close multiple items simultaneously. If you prefer an exclusive accordion (where opening one automatically closes the others), you can easily loop through all items and remove the active class before toggling the clicked one.
